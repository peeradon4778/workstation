1Applied AI / LLM Agents

ทำไมสำคัญกับคุณ: AI กำลังพลิกทุกวงการ — Upwork 2025 มี demand AI/ML +40%, งาน gen-AI ได้ค่าแรง premium (~+22%) บริษัทจ้างคนที่สร้าง agent/automation ใช้ได้จริง ไม่ใช่แค่คุยกับ AI
คุณ: 🟢 มีฐานแล้ว (AI/CV) → ต่อยอดเป็น agent/automation ง่ายสุด

Learning path

  1. ภาษาอังกฤษ Python + ลงมือสร้าง API call กับ LLM (OpenAI/Claude) 1 ตัว
  2. เรียนรู้ RAG (retrieve + answer) สร้าง chatbot ที่อ้างอิงเอกสารได้
  3. สร้าง agent ที่ใช้เครื่องมือ (tool calling) ทำหลายขั้นตอนเอง
  4. Deploy ขึ้น cloud ฟรีให้คนใช้ได้จริง (แชร์กับผู้ว่าจ้าง)

ทรัพยากรฟรีที่ดีที่สุด

Karpathy — Neural Networks: Zero to Hero (ฟรี, คัมภีร์) Hugging Face — Agents & LLM Courses (ฟรี) deeplearning.ai — Andrew Ng: GenAI + Prompt Engineering (ฟรี) fast.ai — Practical Deep Learning (ฟรี) NN & Deep Learning — book ฟรี
ทำก่อนเลย: สร้าง chatbot 1 ตัวที่อ่านไฟล์ (RAG) แล้ว deploy ให้ chat ใช้ได้จริงในสัปดาห์แรก

คุณ: 🟢 เหมาะสุด — เลือก "ประเมินความเสี่ยง climate/energy" + agri

  3. เอา AI มาแก้เฉพาะปัญหา → ทำ case study ที่แสดงผลลัพธ์
  4. แพ็กเป็น offer ขายได้ (เชื่อม SALES.md)

ทำก่อนเลย: เขียน 1 หน้า: "ปัญหา X ในอุตสาหกรรม Y + ใช้ AI แก้ยังไง + ข้อมูลจากไหน" (มาจาก PLAN.e / NICHE)

5Geospatial / Earth-observation AI

ทำไมสำคัญ: climate change + sustainability + insurance → ต้องการข้อมูลจากดาวเทียม/สภาพอากาศมากขึ้นเรื่อยๆ และยังมีคนเก่งน้อย
คุณ: 🟢 ขอบเฉพาะตัว (GISGPT + VitroVision ไม่มีใครเหมือน)

Learning path

  1. Remote sensing พื้นฐาน (Emissary/Normalized indices, NDVI)
  2. GIS: QGIS + Python (Rasterio, GeoPandas, GDAL)
  3. Google Earth Engine (GEE) — วิเคราะห์ภาพดาวเทียมฟรี
  4. ดาวเทียม × weather × ML → correlation / การพยากรณ์

ทรัพยากรฟรีที่ดีที่สุด

NASA ARSET — หลักสูตร remote sensing ฟรี ESA Sentinel / Copernicus — ข้อมูลดาวเทียมฟรี Google Earth Engine — tutorials ฟรี QGIS — GIS ฟรี Rasterio / GeoPandas — Python geospatial
ทำก่อนเลย: ทำ 1 โน้ตบุ๊ค: NDVI จากภาพดาวเทียมพื้นที่หนึ่ง + เห็นผลจริง (ต่อยอดจาก GISGPT)
