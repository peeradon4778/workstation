## 3. 🔑 ช่องว่างที่ยืนยันแล้ว — และความจริงที่ต้องยอมรับ

### สิ่งที่ทุกคนขาย

| กลุ่ม | ตัวอย่าง |
| --- | --- |
| **สร้างระบบให้** (ส่วนใหญ่) | automation · chatbot · agent · RPA · web scraping |
| **สอน** | shanti · zarnzarn · yingnui |
| **ที่ปรึกษา** | yingnui · zsevens |

### สิ่งที่ยังไม่มีใครขายเป็นสินค้าเดี่ยว

> **"ตั้งค่า harness ที่คุณมีอยู่แล้ว ให้ตรงกับ workflow ของคุณ"**

เจ้าใกล้สุดคือ `zsevens` (ออกแบบ+ปรับแต่ง Agent) และ `automationpro` (ปรับแต่งให้เข้ากับธุรกิจ)
— **แต่ทั้งคู่ขายเป็น "สร้างระบบครบวงจร" ไม่ใช่ "ปรับของเดิม"**

### ⚠️ แต่ต้องอ่านให้ถูก

ช่องว่างนี้อาจแคบ **ไม่ใช่เพราะไม่มีคนคิด** แต่เพราะ **กลุ่มลูกค้ายังเล็ก**
→ ลูกค้า Fastwork ส่วนใหญ่คือ **SME ที่อยากได้ระบบ** หรือ **อยากเรียน AI** ไม่ใช่ **ทีมที่ใช้ coding agent อยู่แล้วและรู้ว่าต้องตั้งค่า**

**สรุป:** เป็น **ตลาดเล็กแต่เกิดใหม่** — ต้องอ่านทั้งสองทาง
| 🟢 ถ้าอ่านบวก | 🔴 ถ้าอ่านลบ |
| --- | --- |
| มาก่อน = ได้เปรียบ | ลูกค้าบน Fastwork อาจยังไม่เยอะ |
| กลุ่มโตเร็ว (คนแห่ใช้ coding agent) | ต้องรอตลาดโต |

**→ วิธีรับมือ: ทำหน้างานที่ "จับได้ทั้งสองกลุ่ม"** (คำที่แคบ + คำที่กว้าง อยู่ในชื่องานเดียวกัน)

## 4. ⚠️ ข้อค้นพบที่กระทบแผน — "การค้นพบบน Fastwork"

**สิ่งที่บอกได้:**

- หลักฐาน: URL ที่เห็นมี `source=web_marketplace_search_ads` · `aff_id=` · `position=` → **มีการยิงโฆษณาภายใน**

> คำที่คนค้นหา: `AI Automation` · `n8n` · `Chatbot` · `AI Consultant` · `Claude Code` · `Cursor` · `Vibe Coding`
