## ช่องที่ 3 — คำอธิบาย (Product Description)

### 🅰️ เวอร์ชัน A — ยังไม่มีพอร์ต (ใช้ตอนนี้)

```text
คุณใช้ AI coding agent อยู่ แต่รู้สึกว่ามันยังไม่เข้าใจงานคุณ?

ทุกครั้งที่เปิดโปรเจกต์ใหม่ คุณต้องอธิบายซ้ำว่าทีมทำอะไร โครงสร้างเป็นยังไง
ใช้เครื่องมืออะไร — และคำตอบที่ได้ก็ยังต้องมานั่งแก้เองอยู่ดี

ผมตั้งค่า harness ให้ตรงกับงานของคุณ
ไม่ใช่สอนทฤษฎี แต่ปรับให้ใช้ได้เลย

——— สิ่งที่ผมทำ ———
• ปรับ context และ model ให้เหมาะกับงานที่คุณทำจริง
• เขียน prompt template ที่ใช้ซ้ำได้กับงานประจำของคุณ
• ทำ skill / extension สำหรับงานที่คุณทำซ้ำบ่อย
• ตั้งค่า tool และ permission ให้ปลอดภัยและเร็ว
• สอนวิธีใช้ setup ของคุณ (วิดีโอสั้น + เอกสาร 1 หน้า)

——— คุณจะได้ ———
• ไฟล์ setup ที่ใช้ได้เลย ไม่ต้องเริ่มจากศูนย์
• prompt template 3–8 อัน (ตามแพ็กเกจ)
• เอกสารวิธีใช้ 1 หน้า
• วิดีโออธิบาย 10 นาที (แพ็กเกจขั้น 2 ขึ้นไป)

——— เหมาะกับใคร ———
• นักพัฒนา / ทีมเทคที่ใช้ Claude Code หรือ Cursor อยู่แล้ว
• ทีมที่อยากให้ทุกคนใช้ setup เดียวกัน
• คนที่รู้สึกว่า AI agent ยังไม่ตอบโจทย์งานตัวเอง

——— ทำไมเลือกผม ———
• ผมใช้และปรับแต่ง harness เองทุกวัน — ไม่ได้อ่านจากบทเรียน
• ผมเคยสอนคนที่ใช้ไม่เป็น จนใช้งานได้จริง
• ผมระบุชัดว่าได้อะไร กี่ชิ้น กี่วัน — ไม่มาก ไม่น้อย
• ส่งให้ดูก่อนอนุมัติ ไม่ตรงแก้ให้

💬 ทักมาปรึกษาก่อนได้ฟรี 15 นาที
บอกว่าคุณทำงานอะไร ใช้อะไรอยู่ — ผมจะบอกว่าตั้งค่าอะไรให้ได้บ้าง
ถ้าไม่เหมาะ ผมจะบอกตรงๆ
```

```text

   บอกงานที่คุณทำ ใช้ harness อะไร และติดตรงไหน

   ผมจะแนะนำแพ็กที่พอดีกับงานคุณ — ไม่ขายเกินจำเป็น

3. คุณส่งข้อมูลที่ผมต้องใช้
   • ตัวอย่างงาน 2–3 ชิ้น
   • โครงสร้างโฟลเดอร์ / โปรเจกต์
   • เครื่องมือที่ใช้ประจำ
   • สิ่งที่รู้สึกว่าติดขัด

4. ผมตั้งค่าให้ + ส่งให้ดูก่อนอนุมัติ
   ส่ง setup + เอกสาร + วิดีโออธิบาย
   ไม่ตรงที่ไหน บอกได้เลย แก้ตามจำนวนครั้งในแพ็กเกจ

5. อนุมัติ → ส่งมอบ
   ได้ไฟล์ setup ที่ใช้ได้ทันที
```
