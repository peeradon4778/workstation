# PORTFOLIO — อันไหนโชว์ได้ และลูกค้าอยากเห็นอะไร

> **แก้จากคำขอเดิมของผม:** ผมเคยขอ "แคปหน้าจอ setup 8–10 รูป" — **คำขอนั้นผิด**
> ภาพ config ลูกค้าดูไม่รู้ว่าดีหรือห่วย · ต้องเป็น **คลิปสั้นที่โชว์ผล**

## 1. 📊 จัดอันดับ 8S — อันไหน "โชว์ได้"

| # | โซลูชัน | ของที่โชว์ได้ | โชว์ได้แค่ไหน |
| --- | --- | --- | --- |
| **S6** | MCP Server | **คลิป: ถาม AI → มันดึงข้อมูลจริงจาก API → ตอบ** | 🟢🟢🟢 **ดีสุด** — ดูเหมือนเวทมนตร์ |
| **S3** | Skill / Extension | **คลิป: สั่งคำเดียว → ทำงานหลายขั้นเสร็จเอง** | 🟢🟢🟢 **ดีสุด** — เห็น "ความสามารถใหม่" ชัด |
| **S2** | Prompt Templates | **คลิป: เทียบ "ไม่มี setup" vs "มี setup"** | 🟢🟢 ดีมาก |
| **S7** | Cost Audit | **รายงาน + กราฟตัวเลข ก่อน/หลัง** | 🟢🟢 ดีมาก — ตัวเลข = หลักฐาน |
| **S4** | Context & Model Tuning | **ตัวเลข + กราฟ** | 🟢🟢 ดีมาก |
| **S1** | Setup & Onboarding | โครงไฟล์ + หน้าจอ | 🟡 **โชว์ได้ แต่คนดูตัดสินไม่ได้ว่าดีแค่ไหน** |
| **S5** | Team Packaging | โครง repo + git clone | 🟡 โชว์ได้ แต่ไม่ตื่นเต้น |
| **S8** | Team Training | สไลด์ + **รีวิวจากผู้เรียน** | 🔴 **โชว์ได้แย่สุด** — ต้องมีรีวิวจริง |

### 🔑 อ่านตารางนี้ให้ดี

> **สิ่งที่โชว์ดีสุด = S6, S3, S2, S7**
> **สิ่งที่โชว์แย่สุด = S1, S5, S8** ← ซึ่งเป็น **"การตั้งค่า" และ "การสอน"** ที่คุณคิดว่าจะโชว์

**→ แปลว่า: สิ่งที่คุณอยากโชว์ที่สุด (setup ที่ทำไว้) คือสิ่งที่โชว์ได้แย่ที่สุด**
**เพราะลูกค้าดูภาพ config แล้วตอบไม่ได้ว่า "อันนี้ดีไหม"**

## 2. 🎯 ลูกค้าอยากเห็นอะไร — 5 อย่าง

จากรีวิวจริง + สิ่งที่ลูกค้าถามในใจ

| # | ลูกค้าอยากเห็น | ทำไม | โชว์ด้วยอะไร |
| --- | --- | --- | --- |
| **1** | **"มันทำงานจริงไหม"** | รีวิวพูด *"ใช้งานได้จริง"* | **คลิปที่ของทำงาน** ไม่ใช่ภาพนิ่ง |
| **2** | **"ฉันจะได้อะไร"** | รีวิวพูด *"ได้สิ่งที่ต้องการครบ"* | **ตัวอย่างของที่ส่งมอบจริง** (ไฟล์ · เอกสาร) |
| **3** | **"ใช้กับงานฉันได้ไหม"** | กลัวว่าของจะไม่ตรง | **คลิปที่ใช้โจทย์ใกล้ของเขา** |
| **4** | **"เห็นผลต่างจริงไหม"** | อยากรู้ว่าคุ้ม | **ตัวเลขก่อน/หลัง** + กราฟ |
| **5** | **"ถ้าไม่ตรงล่ะ"** | กลัวที่สุด | **ประโยค "ส่งให้ดูก่อนอนุมัติ"** (ไม่ใช่ภาพ) |

> ### ❌ สิ่งที่ลูกค้า **ไม่** อยากเห็น
> • ภาพหน้าจอ extension ที่ติดตั้งแล้ว · ภาพไฟล์ config · ภาพโครงสร้างโฟลเดอร์
> • โลโก้เครื่องมือ · ภาพจากสต็อก · สกรีนช็อตโค้ดยาวๆ
> **เพราะทั้งหมดนี้ บอกไม่ได้ว่า "ได้ผลอะไร"**

## 3. 🎬 สิ่งที่ต้องอัดจริง — 5 คลิปสั้น

> **แทน 8–10 ภาพนิ่ง ให้เป็น 5 คลิปสั้น** · อัดหน้าจอด้วยมือถือหรือโปรแกรมอัดฟรี
> **ไม่ต้องตัดต่อให้สวย** — ขอให้เห็นว่ามันทำงาน · ใช่ซับแทนเสียงพากย์ได้

| # | คลิป | ความยาว | อัดอะไร | ตอบคำถามข้อ |
| --- | --- | --- | --- | --- |
| **1** | **"คำสั่งสั้น ได้งาน"** | 20 วิ | เปิด agent → พิมพ์ 1 บรรทัด → มันทำงานหลายขั้นเสร็จเอง → ชี้ผลลัพธ์ | 1, 3 |
| **2** | **"ตั้งครั้งเดียว ใช้ซ้ำ"** | 20 วิ | โชว์ skill 1 อัน → สั่งชื่อเดียว → ทำงานเสร็จ | 1, 3 |
| **3** | **"ตัวเลขลดลง"** | 20 วิ | โชว์ token ก่อน → หลัง → กราฟ | 4 |
| **4** | **"AI ดึงข้อมูลจริง"** | 30 วิ | ถาม AI → มันเรียก API → ตอบพร้อมข้อมูลที่ดึงมา (S6) | 1, 3 |
| **5** | **"ของที่คุณจะได้"** | 15 วิ | เลื่อนดูไฟล์ที่ส่งมอบ — เอกสาร · template · โครง setup | 2 |

### 🎯 หลักการอัด
- **ใส่ซับข้อความสั้นๆ บนจอ** — "ก่อน" / "หลัง" / "พิมพ์แค่บรรทัดเดียว"
- **อย่าให้เห็นข้อมูลส่วนตัว** — ใช้โปรเจกต์ตัวอย่าง
- **ถ้าอัดพลาด 2-3 ครั้งก็โอเค** — ของจริงดูน่าเชื่อถือกว่าตัดต่อเนียน
- **ความยาวรวม 5 คลิป ≈ 2 นาที** — ยาวกว่านี้คนไม่ดู

## 4. 📦 และ "ตัวอย่างของที่ส่งมอบ" — ของที่โชว์ได้โดยไม่ต้องอัด

**ทำ 3 อย่างนี้ไว้เป็นไฟล์ให้โหลดดูได้** — ลูกค้าเปิดดูเองได้ ไม่ต้องขอ

| # | สิ่งที่ทำ | ทำไมได้ผล |
| --- | --- | --- |
| **1** | **Prompt template 1 อัน (ของจริง)** | ลูกค้าเปิดอ่านได้ ว่าได้อะไร |
| **2** | **เอกสาร setup 1 หน้า (ตัวอย่าง)** | เห็นว่างานเรียบร้อย |
| **3** | **ตัวอย่างรายงานก่อน/หลัง (สำหรับ S7)** | ถ้าเป็นตัวเลข → น่าเชื่อถือสุด |

> **ระวัง:** ลบข้อมูลจริง/ชื่อจริงออก · ใช้โปรเจกต์ตัวอย่างของคุณเอง

## 5. 🎯 ลำดับที่ควรสร้างพอร์ต

```text
1. คลิป 1 "คำสั่งสั้น ได้งาน"     ← ง่ายสุด ใช้ของที่ใช้อยู่แล้ว
        ↓
2. คลิป 5 "ของที่คุณจะได้"       ← ง่าย ถ่ายไฟล์
        ↓
3. คลิป 3 "ตัวเลขลดลง"           ← ⚠️ ต้อง "วัดจริง" วัดไม่ได้ = อย่าใส่
        ↓
4. คลิป 2 "ตั้งครั้งเดียว ใช้ซ้ำ"  ← ต้องตั้ง skill จริง
        ↓
5. คลิป 4 "AI ดึงข้อมูลจริง"      ← ยากสุด (MCP) แต่โชว์ดีสุด
```

**ทำ 1–3 ได้ก่อน → พอลงหน้างานได้แล้ว** · 4–5 เติมทีหลัง

## 6. ⚠️ 3 ข้อห้าม

| ห้าม | เพราะ |
| --- | --- |
| **ใส่ตัวเลขที่ยังไม่ได้วัด** | ถ้าลูกค้าถามว่า "วัดยังไง" แล้วตอบไม่ได้ = เสียเครดิตทันที |
| **ใช้คลิปคนอื่น / ภาพสต็อก** | ตรวจสอบได้ + ผิดกฎแพลตฟอร์ม |
| **อัดคลิปยาว 10 นาที** | ไม่มีใครดู · พอร์ตต้องดูจบใน 30 วิ ต่อชิ้น |
