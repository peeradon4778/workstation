# Business Plan — Shopee Affiliate (A) → Tool (C)

> **เส้นทางที่เลือก: ใช้เองก่อน → แล้วค่อยเป็นเครื่องมือขาย**
> **ขั้น 1 — ใช้เอง:** วิ่งช่อง Shopee Affiliate ของตัวเอง 1 ช่อง โดยใช้ AI เป็น *โรงงานผลิต* (ไม่ใช่บอทโพสต์)
> **ขั้น 2 — ขายเครื่อง:** แพ็กสิ่งที่เรียนรู้จากการใช้จริง เป็น *เครื่องมือ* ขายให้คนอื่น (margin เป็น software ไม่ใช่ 2%)
>
> **สถานะ:** ยังไม่มีกลุ่มลูกค้า — และยังไม่ต้องมี เป้าตอนนี้คือ *ทำให้มันทำงานกับตัวเองได้ก่อน*
>
> **Scope: business only.** งานเทคนิค/การเรียน แยกอยู่ที่ของตัวเอง ไม่ดึงมาไว้ในนี้

## กลยุทธ์ 1 บรรทัด

**ใช้ AI ผลิตคอนเทนต์วิดีโอให้ช่อง affiliate ของตัวเอง → วัดด้วย `sub_id` ว่าอะไรทำให้คนคลิกและซื้อ → เอาวงจรนั้นไปเป็นสินค้า**

## โรงงานที่ใช้อยู่

`tools/affiliate_factory/app.py` — รัน `python app.py` → <http://localhost:8777>
ใส่สินค้า 1 ตัว (หรือวางเป็นแบทช์) → ได้ hook 5 แบบ · สคริปต์ 15–30 วิ · shot list · แคปชัน · แฮชแท็ก · ลิงก์ + `sub_id`

## ทำไมต้อง A ก่อน

| | ถ้าทำ A ก่อน (เลือกแล้ว) | ถ้าข้ามไป C เลย |
|---|---|---|
| ความรู้เรื่องลูกค้า | เห็นข้อมูลจริงจากหลังบ้านตัวเอง | เดาเอา |
| ต้นทุนความผิดพลาด | 0 บาท, เสียแค่เวลา | สร้างของที่ไม่มีใครต้องการ |
| ได้อะไรกลับมา | ทราฟฟิก + คอม + ข้อมูล | โค้ดที่ไม่มีคนใช้ |

A คือ **ห้องแล็บที่จ่ายเงินให้เราเรียน** — C คือของจริงที่ต้องแม่น

## ⛔ กฎเหล็ก 7 ข้อ (ผิดข้อเดียว = แบน = งานหายทั้งหมด)

1. **AI เป็นโรงงาน ไม่ใช่บอท** — มนุษย์เป็นคนกด PUBLISH เสมอ ไม่มี auto-post
2. **≤ 30 ลิงก์ affiliate/วัน** — เกินนี้คือ spam flag ตามแนวปฏิบัติ Shopee Affiliate
3. **ดึงข้อมูลผ่าน Product Feed / AMS Open API ทางการเท่านั้น** — ToS 6.4 ห้าม robots / automated query tools / computer-generated search requests
4. **ห้ามเอาคอนเทนต์ affiliate คนอื่นมาโพสต์** — Shopee ระบุ *plagiarism* เป็น ban reason อันดับ 1
5. **เปิดเผยทุกโพสต์ว่าเป็นลิงก์ affiliate**
6. **ห้ามซื้อผ่านลิงก์ตัวเอง** (หักคอม / แบน)
7. **ห้ามทำเว็บฟาร์ม AI-mass** — Google core update มี.ค. 2026 ลงโทษ scaled content abuse → ทราฟฟิกหาย 50–80%

## 💰 คณิตศาสตร์ที่ต้องชนะ (ตัวเลขจริง Shopee TH, 2026)

| พารามิเตอร์ | ค่าจริง |
|---|---|
| คอม Direct Order | **2.00%** (ผลตั้งแต่ 20 เม.ย. 2026) |
| คอม Indirect Order | **0.60%** |

| หมวด 0% | Utilities, Donation, Local Service, Investment |

**สมการ:** `รายได้ = GMV × 2%` → **GMV = รายได้ × 50**

| เป้ารายได้ | ต้องได้ GMV | ที่ออเดอร์เฉลี่ย 400 ฿ = จำนวนออเดอร์ |
|---|---|---|
| คอมแรก (ออเดอร์แรก) | ~400 ฿ | 1 |
| **ถอนได้จริงรอบแรก** | **75,000 ฿ (สะสม)** | **188** |
| 5,000 ฿/เดือน | 250,000 ฿/เดือน | 625 |
| 10,000 ฿/เดือน | 500,000 ฿/เดือน | 1,250 |

> 10,000 ฿/เดือน ≈ **42 ออเดอร์/วัน ≈ 2,100 คลิก/วัน ≈ 140,000 impressions/วัน**
> ไม่มีงบโฆษณา → **วิดีโอสั้นคือเครื่องเดียวที่ให้ทราฟฟิกฟรี** (algorithm แจก distribution)

## PHASE 0 — Unblock (สัปดาห์นี้ · 0 บาท)

> ⏱ **Critical path = 45–60 วันทำการ** ของการอนุมัติบัญชีธนาคาร → **เริ่มวันนี้** ห้ามรอให้คอนเทนต์เสร็จก่อน

- [ ] 0.1 ตัดสินใจเรื่องบัญชี: ถ้าอายุ < 18 → สมัครด้วยบัตรประชาชน/KYC ของผู้ปกครอง (มีเคสเด็ก 15 ทำได้จริง) · ถ้า ≥ 18 → สมัครเอง
- [ ] 0.2 สมัคร Shopee Affiliate (ประเภทรายบุคคล) + ให้ข้อมูลครบภายใน 3 เดือน
- [ ] 0.3 **ผูกบัญชีธนาคาร + ส่ง KYC วันนี้** ← ตัวที่ใช้เวลา 45–60 วัน
- [ ] 0.4 เปิดช่องทาง 3 ช่อง: **TikTok**, **Shopee Video**, **Facebook Page** (ต้องเป็น public)
- [ ] 0.5 ดาวน์โหลด **Product Feed** จาก `Login > Creative > Product Feed` — ทำความเข้าใจ field
- [ ] 0.6 ตั้งรูปแบบ `sub_id` และทดสอบลิงก์ 1 อันให้ครบวงจร (ดู `PIPELINE.md`)

## PHASE 1 — สร้างโรงงาน (สัปดาห์ 2–3)

- [ ] 1.1 Ingest: โหลด Product Feed → ตาราง
- [ ] 1.2 Score: ให้คะแนน "ควรโปรโมทไหม" (ยอดขาย · เรตติ้ง · คอม% · ราคา < 11,250 · ไม่ใช่หมวด 0%)
- [ ] 1.3 Generate: AI ร่างสคริปต์ 15–30 วิ (hook 3 วิแรกต้องจบปัญหา)
- [ ] 1.4 Link: สร้างลิงก์ + `sub_id` ต่อคลิปทุกอัน
- [ ] 1.5 ยิงวิดีโอจริงเอง — **ฟุตเทจต้องเป็นของเรา** (ต้นผักที่ปลูกเอง) ห้ามใช้คลิปคนอื่น
- [ ] 1.6 เก็บคลิป 10 อันให้พร้อมก่อนเริ่มโพสต์

## PHASE 2 — วงจรโพสต์ (สัปดาห์ 3 เป็นต้นไป · ทำทุกวัน)

- [ ] 2.1 โพสต์ 1–2 คลิป/วัน **ด้วยมือ** (≤30 ลิงก์/วัน)
- [ ] 2.2 ใส่ลิงก์ใน **คอมเมนต์/pinned** ไม่ใช่ในตัวคลิป (ลด spam signal)
- [ ] 2.3 เปิดเผยว่าเป็น affiliate link
- [ ] 2.4 ตอบคอมเมนต์ทุกอันใน 24 ชม. (นี่คือ CR engine จริง)

## PHASE 3 — วัดและเรียนรู้ (ทุกอาทิตย์)

- [ ] 3.1 ดึงรายงาน Affiliate → บันทึก `TRACKER.md`
- [ ] 3.2 ดูว่า `sub_id` ไหนได้ GMV → หา pattern
- [ ] 3.3 เขียน 1 บรรทัด: สัปดาห์นี้学到อะไร → ป้อนกลับข้อ 1.3
- [ ] 3.4 ตัด format ที่ CTR ต่ำสุดทิ้ง ทำซ้ำ format ที่ดีที่สุด

## PHASE 4 — Scale (เดือน 4+)

- [ ] 4.1 เพิ่ม 2–3 คลิป/วัน เฉพาะ format ที่พิสูจน์แล้ว
- [ ] 4.2 เพิ่มช่องทาง (Shopee Video, Lemon8, FB Group ที่อนุญาตลิงก์)
- [ ] 4.3 ขึ้นไปแตะเป้า 1,500 ฿ ถอนได้ครั้งแรก
- [ ] 4.4 เก็บข้อมูลให้ครบเพื่อป้อน C

## PHASE 5 — C (ทำเมื่อ A มีข้อมูลพอ)

- [ ] 5.1 สรุป "งานที่ทำซ้ำทุกวันและน่าเบื่อที่สุด" จาก log ตัวเอง
- [ ] 5.2 สัมภาษณ์ affiliate คนอื่น 5 คน (เจอได้ในกลุ่ม FB/TikTok affiliate)
- [ ] 5.3 ตรวจว่าเครื่องมือที่จะขาย แก้ปัญหาที่ *คนอื่น* ก็เจอ ไม่ใช่แค่เรา
- [ ] 5.4 ร่าง offer C → กรอก `OFFER.md` ← ไฟล์นั้นถูกเก็บไว้เพื่อขั้นนี้
- [ ] 5.5 กลับไปใช้ `SALES.md` (แผนขายแบบ consultative) เพื่อหาลูกค้ารายแรก

## ⛔ เกณฑ์เลิก (Kill Criteria — สำคัญที่สุดในแผนนี้)

ตั้งไว้ล่วงหน้าเพื่อไม่ให้จมเป็นปีโดยไม่มีอะไรกลับมา:

- **60 วัน / 40 คลิป แล้ว CTR < 0.5%** → เปลี่ยน **format** ไม่ใช่เปลี่ยน niche
- **90 วัน / 100 คลิป ยังไม่มีออเดอร์เลย** → หยุด ทำ post-mortem แล้วเลือกใหม่
- **6 เดือน แล้วยังไม่แตะ 1,500 ฿** → **หยุด A ย้ายไป C ทันที** (ข้อมูลที่ได้ก็ยังมีค่า)
- รู้สึกว่าต้องใช้ >10 ชม./สัปดาห์เพื่อประคอง → ลด rate ไม่ใช่เพิ่ม
