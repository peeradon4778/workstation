# Pipeline — โรงงานคอนเทนต์ affiliate (สเปก)

> **ปรัชญา:** AI ทำงานชั้น *โรงงาน* (ดึงข้อมูล → ให้คะแนน → ร่าง → สร้างลิงก์ → วัด)
> **มนุษย์** ทำงานชั้น *ผู้จัดจำหน่าย* (ถ่าย → กดโพสต์ → ตอบคอมเมนต์)
> ห้ามข้ามเส้นนี้ — ชั้นที่อยาก automate ที่สุด คือชั้นที่ Shopee ห้าม

## ภาพรวม

```
Product Feed (official)                    ┌─────────────────────────┐
  Login > Creative > Product Feed         │  ห้าม: scrape, บอทคลิก,  │
        │                                 │  auto-post, AI mass page │
        ▼                                 └─────────────────────────┘
   [1] INGEST ──► [2] SCORE ──► [3] GENERATE ──► [4] LINK + sub_id
                                                        │
   [7] FEEDBACK ◄── [6] MEASURE ◄── [5] PUBLISH ◄───────┘
                                          (มนุษย์กด)
```

| # | ชั้น | ใครทำ | ใช้ศาสตรอะไร | Output |
|---|---|---|---|---|
| 1 | INGEST | AI | Product Feed CSV → pandas | ตารางสินค้า |
| 2 | SCORE | AI | สูตรถ่วงน้ำหนัก | ลำดับสินค้าที่ควรโปรโมท |
| 3 | GENERATE | AI | LLM ร่างสคริปต์/แคปชัน | draft 15–30 วิ |
| 4 | LINK | AI | Product Feed short-link fields | ลิงก์ + `sub_id` |
| 5 | PUBLISH | **มนุษย์** | มือถือ, ≤30 ลิงก์/วัน | คลิป/โพสต์จริง |
| 6 | MEASURE | AI | Affiliate report + Analytics API | ตัวเลขลง `TRACKER.md` |
| 7 | FEEDBACK | AI + มนุษย์ | เทียบ `sub_id` | prompt / น้ำหนักใหม่ |

---

## [1] INGEST

- **แหล่งข้อมูลที่ถูกกฎหมาย:** `Login > Creative > Product Feed` (ดาวน์โหลดจากหลังบ้าน), และ **Shopee AMS Open API** (`open.shopee.com`)
- **ฟิลด์ที่ต้องได้:** `item_id` · ชื่อ · ราคา · คอม% · ยอดขาย · เรตติ้ง · หมวด · ชนิดร้าน · ลิงก์สินค้า (landing page) · ช่อง short-link
- **เก็บที่:** `data/feed-YYYYMMDD.csv` — **อย่า commit ไฟล์ข้อมูลลง git** (เพิ่ม `.gitignore` ตอนเริ่มเขียนโค้ด)

## [2] SCORE — เลือกสินค้าที่ควรโปรโมท

**ตัวกรองแข็ง (hard filter) — ตัดทิ้งทันที:**
- หมวด Utilities / Donation / Local Service / Investment (คอม 0%)
- ราคา ≥ 11,250 ฿ (ชนเพดาน 225 แล้วไม่คุ้มความพยายาม)
- เรตติ้ง < 4.5

**ให้คะแนน (ปรับน้ำหนักได้เมื่อมีข้อมูลจริง):**

| ปัจจัย | ทิศทาง | น้ำหนักเริ่มต้น |
|---|---|---|
| คอม% | สูง = ดี | ★★★★ |
| ยอดขาย/เดือน (log) | สูง = ดี (มีดีมานด์พิสูจน์แล้ว) | ★★★★ |
| เรตติ้ง | สูง = ดี | ★★ |
| ราคา 300–2,000 ฿ | อยู่ในช่วง = ดี | ★★★ |
| Shopee Mall | ใช่ = ดี | ★ |
| ต้องใช้ความรู้อธิบาย | ใช่ = ดี (คู่แข่ง copy ยาก) | ★★★ |

> **ทำไมต้องให้คะแนน:** ตอน AOV ~400 ฿ ต้องได้ ~42 ออเดอร์/วัน → คลิปต้องยิงถูกตัว
> ยิงผิดตัวคือการเผาเวลาที่แพงที่สุด

## [3] GENERATE — ร่างคอนเทนต์

**Format ที่ใช้ (เรียงตามความสำคัญ):**
1. **Timelapse การเติบโตของผัก** ⭐ — จุดแข็งเฉพาะตัว (ทำได้จาก CV ของเรา) และ algorithm ชอบ
2. **Before / After** — ก่อนใส่ปุ๋ย → หลัง 14 วัน
3. **ปัญหา → สินค้า** — "ใบเหลืองเพราะ..." → อุปกรณ์/น้ำยาที่ใช้
4. **เทียบให้ดู** — ของถูก vs ของที่ใช้จริง
5. **สอน 30 วิ** — วิธีผสมปุ๋ย A/B

**โครงสคริปต์ที่บังคับ (15–30 วิ):**

| วิ | ส่วน | ห้าม |
|---|---|---|
| 0–3 | **Hook** = ปัญหาของคนดู (ไม่ใช่ชื่อสินค้า) | ห้ามขึ้นด้วย "สวัสดีค่ะ" หรือชื่อร้าน |
| 3–10 | โชว์ของจริง | ห้ามใช้คลิปคนอื่นเด็ดขาด |
| 10–22 | วิธีใช้ + ผลลัพธ์ | ห้ามเคลมเกินจริง (ผิดกฎโฆษณา) |
| 22–30 | CTA + "ลิงก์ในคอมเมนต์" | ห้ามใส่ลิงก์ในตัวคลิป |

**Hook 5 แบบ (ใช้ทดสอบ):** *ทำไมผักตายทั้งชุด* · *3 อย่างที่มือใหม่ซื้อผิด* · *ปลูกในระเบียงได้จริงไหม* · *ค่าน้ำค่าไฟไฮโดรกี่บาท* · *เมล็ด 20 บาท vs 200 บาท*

**เครื่องมือ:** LLM ร่างสคริปต์ · ffmpeg ตัดต่อ · TTS พากย์ (หรือพากย์เอง — ดีกว่า) · ใส่ซับอัตโนมัติ

## [4] LINK + `sub_id` — หัวใจของการวัดผล

สร้างตาม **Affiliate Short Link Implementation Guide** ของ Shopee:

```
https://{domain}/an_redir?origin_link={encoded_landing_page}&affiliate_id={id}&sub_id={sub}
```

**รูปแบบ `sub_id` ของเรา (สูงสุด 5 ส่วน คั่นด้วย `-`):**

```
{publisher}-{content_id}-{platform}-{format}
    p01   -   c007    -    tt    -  vid
```

| ส่วน | ค่า |
|---|---|
| publisher | `p01` (คงที่ — เรามีช่องเดียว) |
| platform | `tt` TikTok · `sv` Shopee Video · `fb` Facebook · `lm` Lemon8 |
| format | `vid` timelapse · `ba` before/after · `pr` ปัญหา→สินค้า · `cmp` เทียบ · `hw` สอน |

> **ถ้าไม่มี `sub_id` = วัดผลไม่ได้ = เรียนรู้อะไรไม่ได้ = ทั้ง A ไม่มีค่าและ C เกิดขึ้นไม่ได้**
> นี่คือส่วนที่ทำให้โปรเจกต์นี้มีค่ามากกว่าค่าคอม 2%

## [5] PUBLISH — มนุษย์เท่านั้น

- [ ] 1–2 คลิป/วัน ต่อช่อง
- [ ] **นับลิงก์รวมทุกช่อง ≤ 30/วัน**
- [ ] ลิงก์อยู่ในคอมเมนต์แรก + ปักหมุด
- [ ] เปิดเผยว่าเป็นลิงก์ affiliate
- [ ] ตอบทุกคอมเมนต์ภายใน 24 ชม. ← ตัวขับ CR จริง

## [6] MEASURE

ดึงจากหน้ารายงาน Affiliate (Products / Performance / Affiliate Analytics API) แล้วบันทึก:
`impressions` · `clicks` · `CTR` · `orders` · `GMV` · `commission` · `sub_id`

**ตัวชี้วัดที่ต้องจับตา (เรียงตามลำดับที่ควรสนใจ):**
1. **CTR** (impressions → clicks) — บอกว่าคอนเทนต์ดีไหม
2. **CR** (clicks → orders) — บอกว่าคนดู *ตั้งใจซื้อ* ไหม
3. **GMV/คลิก** — บอกว่าเลือกสินค้าถูกไหม (ตัวนี้ควรดีขึ้นเรื่อยๆ)

> รายได้ = traffic × CTR × CR × AOV × 2% — ตัวที่ AI ควบคุมได้จริงคือ **CTR** และ **การเลือกสินค้า**

## [7] FEEDBACK — วงจรที่ทำให้มันเป็น "AI automation" จริง

ทุกอาทิตย์:
1. จัดอันดับ `sub_id` ด้วย GMV
2. เทียบ `format` → ห้ามเดา ให้ใช้ตัวเลขตัดสิน
3. เขียน 1 บรรทัดลง **Decision Log** ใน `TRACKER.md`
4. ปรับ: prompt · hook · น้ำหนักใน SCORE · ตัด format ที่แพ้ทิ้ง

**นี่คือสิ่งที่จะกลายเป็นสินค้า C** — ไม่ใช่ "AI เขียนแคปชัน" แต่คือ **วงจรวัดผล → ปรับ → วัดผล ที่พิสูจน์จากบัญชีจริงของเราเอง**

---

## ❌ สิ่งที่เราจงใจ *ไม่* automate

| ไม่ทำ | ทำไม |
|---|---|
| auto-post ไป FB group / หลายบัญชี | ToS + Meta ตัด `publish_to_groups` ตั้งแต่ เม.ย. 2025 |
| บอทคลิก / ปลอม impression | ToS 6.4 + เป็นการฉ้อโกง |
| scrape Shopee | ผิด ToS — ใช้ Product Feed แทน |
| ฟาร์มเว็บ AI หลักพันหน้า | Google มี.ค. 2026 ตัดทราฟฟิก 50–80% |
| copy คลิปคนอื่น | ban reason: plagiarism |
| ซื้อผ่านลิงก์ตัวเอง | หักคอม / แบน |

## 🔧 ลำดับสร้าง (MVP = 1 สุดสัปดาห์)

| ลำดับ | ทำอะไร | ทำไมก่อน |
|---|---|---|
| 1 | โหลด Product Feed → ตาราง + filter แข็ง | ได้รายชื่อสินค้าที่ควรโปรโมททันที |
| 2 | สร้างลิงก์ + `sub_id` ด้วยมือ 5 อัน | ทำให้การวัดผล "มี" ก่อนสร้างของเยอะ |
| 3 | ยิง 5 คลิป + โพสต์ + วัดผล | พิสูจน์วงจรครบก่อนขยาย |
| 4 | ค่อยเขียน SCORE + GENERATE อัตโนมัติ | อย่าเขียนโค้ดก่อนรู้ว่าคอนเทนต์แบบไหนเวิร์ก |

> **กับดักที่ต้องหลบ:** เขียน pipeline สวยๆ 2 สัปดาห์ แล้วไม่เคยโพสต์สักคลิป
> ลำดับ 3 ก่อน 4 เสมอ — **โพสต์ก่อน แล้วค่อยสร้างเครื่อง**
