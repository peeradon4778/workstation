# META — วิธีเพิ่มการมองเห็นบน Fastwork

> ข้อมูลจากเอกสารทางการของ Fastwork (Fastwork Score · นโยบายลงงาน · ระบบ Ads · Rehire badge)
> ใช้ไฟล์นี้ตอน **ตั้งชื่อหน้างาน + เขียนรายละเอียด + ใส่สกิล**

## 1. 🎯 Fastwork Score — ระบบจัดอันดับ (ทางการ)

> *"Fastwork พัฒนาระบบ **Fastwork Score** เพื่อใช้ประกอบการจัดอันดับหน้างานบนหน้าหมวดหมู่ โดยพิจารณาจากข้อมูลหลายด้านร่วมกัน"*

**6 ปัจจัยหลัก — ที่ยืนยันได้:**

| # | ปัจจัย | รายละเอียด |
| --- | --- | --- |
| 1 | **ระยะเวลาตอบกลับ** | เฉลี่ยในช่วง **60 วัน** ที่ผ่านมา — **⚠️ การตอบกลับอัตโนมัติไม่ถูกนับ** |
| 2 | **อัตราการจ้างงาน** | จำนวนลูกค้าที่เลือกใช้บริการในช่วง 60 วัน |
| 6 | **อัตราการจ้างซ้ำ (Rehire)** | % การจ้างจากลูกค้าเดิม — **ปี 2024 เพิ่มน้ำหนักข้อนี้มาก** |

> *"ฟรีแลนซ์ที่มีอัตราจ้างซ้ำสูงจะมีคะแนน fastwork score สูงขึ้น ทำให้มีโอกาสได้อันดับงานสูง"*

**เกณฑ์ Rehire Badge:** แต่ละหมวดต่างกัน — กลุ่มอัตราจ้างซ้ำต่ำ = **จ้างซ้ำ ≥20% และถูกจ้าง ≥5 ครั้ง**

### ✅ สิ่งที่ควบคุมได้ตั้งแต่วันแรก (ยังไม่มีรีวิว)

| ทำได้เลย | หมายเหตุ |
| --- | --- |
| **ตอบแชทเร็ว** | ปัจจัย #1 — และ **ห้ามใช้ข้อความอัตโนมัติ** |
| **ออนไลน์บ่อย** | ทางการแนะนำตรงๆ |
| **จำนวน Product Card** | ⭐ ดูข้อ 2 |
| **คำในชื่อ + รายละเอียด** | ให้ตรงคำค้นจริงของลูกค้า |
| **รูปผลงาน** | ตรงกับบริการ |
| **ยอดชำระผ่าน Fastwork** | ⚠️ ทำงานนอกระบบ = **ไม่นับ** |

## 2. 🔑 กลยุทธ์หลัก: **แตกหน้างานตามคำค้น — อย่ารวมเป็นอันเดียว**

จากเอกสารทางการ (หมวดเช่ารถ ขยายใช้ได้ทุกหมวด):

> *"**จำนวน Product Card** ที่คุณสร้าง **มีผลโดยตรงต่อการมองเห็น** — ยิ่งมีมาก โอกาสลูกค้าค้นเจอสูงขึ้น"*
> *"**อย่ารวมไว้ใน Product เดียว** ให้แยกสร้างเป็นหลาย Card เพื่อให้ระบบแสดงผลครอบคลุมทุกคำค้นที่ลูกค้าใช้"*
> *"**ตั้งชื่อ Product Card ให้ตรงกับคำค้นหาจริงของลูกค้า** — ช่วยให้ระบบ Fastwork เข้าใจ"*

**ข้อกำหนดที่เกี่ยวข้อง:**
- ลงได้ **สูงสุด 5 งาน**
- **1 หน้างาน = 1 หมวดหมู่** — อยากรับหลายประเภท = สร้างหลายหน้างาน
- **ลงหลายงานในหมวดเดียวกันได้แล้ว** (นโยบายใหม่ — ทางการระบุว่าเพื่อ *"เพิ่มโอกาสการค้นพบผ่านระบบค้นหา"*)

> ### ❌ ผิด: 1 การ์ดยัดทุกคำ
> *"รับตั้งค่า AI Coding Agent Claude Code Cursor pi n8n Automation Consultant ลดต้นทุน"*
>
> ### ✅ ถูก: 5 การ์ด แยกตามกลุ่มคำค้น
> การ์ดละ 1 กลุ่ม → **ครอบคลุมคำค้นมากกว่า และดูน่าเชื่อถือกว่า**

**และ:** หน้างาน Fastwork **ถูก index โดย Google** (ทางการระบุ *"ถูกค้นหาผ่าน Google ได้"*) → คำในชื่อ/รายละเอียดมีผลกับ Google ด้วย

## 3. 🗂️ ชั้นคำค้นหา (ต้องมีให้ครบทุกชั้น)

### ชั้น 1 — คำในชื่อหมวดของแพลตฟอร์ม (บังคับ — ไม่มี = ไม่ถูก index)
`AI Consultant` · `AI Automation` · `AI Transformation` · `AI Course` · `AI No Code App` · `AI Tool & SaaS` · `Data Science & AI` · `RPA` · `Prompt Engineering` · `Chatbot`

### ชั้น 2 — ชื่อเครื่องมือ (คนค้นด้วยชื่อเครื่องมือ)

### ชั้น 3 — คำที่ลูกค้าพูด (ไม่ใช่คำที่เราชอบ) ⭐
`ลดต้นทุน` · `ลดค่าใช้จ่าย` · `ประหยัด token` · `ลดงานซ้ำ` · `ทำงานแทนคน` · `ประหยัดเวลา` · `วางระบบ` · **`ตั้งค่า`** · `ปรับแต่ง` · `เชื่อมต่อ` · `ทำให้อัตโนมัติ` · **`ใช้ไม่เป็น`** · `เริ่มยังไง` · `ไม่ต้องเขียนโค้ด`

### ชั้น 4 — กลุ่มลูกค้า
`ทีมเทค` · `ทีม dev` · `นักพัฒนา` · `สตาร์ทอัพ` · `เจ้าของธุรกิจ` · `SME` · `องค์กร`

### ชั้น 5 — ไทย + อังกฤษคู่กัน
คนไทยค้นสลับ → ใส่ทั้งสองภาษาในชื่อและรายละเอียด

> ### ❌ คำที่ห้ามใช้เป็นคำหลัก
> `Harness Configuration` · `Agentic Orchestration` · `Context Engineering` — **ไม่มีคนค้นหาคำเหล่านี้**
> ใช้ได้ในวงเล็บ/รายละเอียด แต่ **ห้ามเป็นคำนำ**

## 5. 📇 5 ชื่องานพร้อมใช้ (แยกตามกลุ่มคำค้น)

> ⚠️ **ห้ามใส่ราคาในชื่องานหรือรูปภาพงาน** — ผิดนโยบาย Fastwork

### การ์ด 1 — หมวด `AI Consultant` ⭐ เริ่มอันนี้
```text
รับตั้งค่า AI Coding Agent (Claude Code · Cursor · pi) ให้ตรงกับงานคุณ
ปรับแต่ง workflow และลดต้นทุน token · ปรึกษาฟรี
```

### การ์ด 2 — หมวด `AI Automation`
```text
รับทำ AI Automation ด้วย n8n และ AI Agent ให้ธุรกิจคุณ
ลดงานซ้ำ · เชื่อมต่อ API · ตั้งค่าจริง ใช้ได้เลย
```

### การ์ด 3 — หมวด `AI Consultant`
```text
รับปรับแต่ง AI Agent ให้ทีม dev ใช้เหมือนกันทั้งทีม
ตั้งค่า context · model · permission · แพ็กเป็น package ให้ติดตั้งง่าย
```

### การ์ด 4 — หมวด `AI Consultant`
```text
ลดต้นทุนค่า API / token ของ AI Agent ที่คุณใช้อยู่
ตรวจและปรับ context · model routing · วัดผลเป็นตัวเลขได้
```

### การ์ด 5 — หมวด `AI Course`
```text
สอนใช้ AI Coding Agent (Claude Code · Cursor) ตัวต่อตัว จับมือทำกับงานจริง
90 นาที / 3 ชม. / 6 ชม. · ปรึกษาฟรีก่อนได้
```

**กลยุทธ์:** เริ่ม **2 การ์ด** (1 + 5) → เมื่อมีเวลา/รีวิว เติมการ์ด 2, 3, 4 จนครบ 5

## 6. ⚠️ กฎที่ห้ามพลาด

| กฎ | รายละเอียด |
| --- | --- |
| **ห้ามใส่ราคาในชื่องาน/รูปภาพ** | ผิดนโยบาย — ใส่ราคาได้แค่ในแพ็กเกจ |

| **หน้างานใหม่รออนุมัติ 48 ชม.** | แก้ไขได้ตลอดโดยไม่หลุดอันดับ (มีระบบฉบับร่าง) |
