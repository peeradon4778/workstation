## 3. รีวิว + บันไดราคา

**เป้าแรก: รีวิว 5 ดาว 1 อัน** — ตัวนี้มีค่ามากกว่ารายได้งานแรก

| รีวิวที่ได้ | ราคาที่ควรตั้ง (ขั้น 1 / 2 / 3 / 4) |
| --- | --- |
| 0–2 | ฿1,500 / ฿4,500 / ฿9,900 / ฿24,900 — เริ่มตรงนี้ อย่าขึ้น |
| 3 | ฿2,500 / ฿5,900 / ฿12,900 / ฿29,900 |
| 5 | +20–30% ทุกขั้น |
| 10 + จ้างซ้ำ 3 ครั้ง | ถึง anchor ตลาด: ฿4,500 / ฿12,000 / ฿25,000 |

- [ ] รีวิวที่ 1
- [ ] รีวิวที่ 3 → ขึ้นราคา
- [ ] รีวิวที่ 5 → ขึ้นอีก
- [ ] ลูกค้าจ้างซ้ำรายแรก
