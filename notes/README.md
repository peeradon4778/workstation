# Notes — Second Brain

A growing garden of what I learn. Not a dump — a system I actually revisit.

## Structure (PARA)

- **Areas** — ongoing responsibilities (geospatial, AI, business, research)
- **Projects** — things with an ending
- **Resources** — links, references, tools, cheatsheets
- **Archive** — done, for reference

## Rules

- Capture quickly, organize later — don't let perfect block the note.
- One idea per note.
- Link notes together with `[[wiki links]]`.
- Review weekly: *what did I learn that I want to keep?*
- Quotes and sparks get tagged `#idea`.

## Starter prompts

- What did I solve today that I might solve again?
- What's a fact about my niche (satellite / geospatial AI) worth remembering?
- What did I learn about business / clients / markets?
